# Adarsh Kashyap — GitHub Profile

Add your portrait as `hero.png` at the repository root.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r scripts/requirements.txt
python scripts/prep_photo.py hero.png
python scripts/make_ascii_svg.py
python scripts/make_info_card.py
python scripts/fetch_contributions.py AADIKASHYAP
python scripts/render_heatmap_svg.py
```

The workflow updates contribution data and the heatmap daily at 06:17 UTC and supports manual runs.

Portfolio, Instagram, Facebook, and project URLs were not invented because verified values were not provided.
